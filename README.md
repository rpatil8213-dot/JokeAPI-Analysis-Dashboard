# JokeAPI-Analysis-Dashboard

A Tableau dashboard created to explore and analyze joke data collected from JokeAPI.

The dashboard looks at different joke categories, joke types, languages, safety settings, and content flags.

## 📊 Dashboard

The dashboard includes analysis of:

- Joke categories
- Joke types
- Languages
- Safe and unsafe jokes
- NSFW and other content flags
- Distribution of jokes across different categories
- Overall joke dataset patterns

## 🛠️ Tools Used

- Tableau
- JokeAPI
- Data Analysis
- Data Visualization

## 📁 Dataset

The project uses a dataset containing **500 jokes** collected from JokeAPI.

The data contains information such as:

- Category
- Joke type
- Language
- Safe/unsafe status
- Content flags
- Joke text

## 🔍 What I Analyzed

Some of the questions explored in the dashboard were:

- Which joke categories have the most data?
- What types of jokes are most common?
- How are jokes distributed across languages?
- How many jokes are marked as safe?
- Which content flags appear most frequently?
- Are certain categories more likely to contain specific content flags?

## 📈 Dashboard Features

The Tableau dashboard provides interactive charts and filters to explore the dataset.

Users can filter the data and compare different categories, joke types, languages, and safety-related attributes.

## 🚀 How to Use

1. Download or clone this repository.
2. Open `JokeAPI_Analysis_Dashboard.twbx` using Tableau Desktop.
3. Open the dashboard.
4. Use the available filters to explore the data.

## 💡 Key Takeaway

This project was mainly built to practice working with a real-world API dataset and turning the data into an interactive Tableau dashboard.

It helped me practice data preparation, basic analysis, calculated fields, filtering, and dashboard design.
